🔍 **Alert Detection & Analysis | SOC – Wazuh SIEM**

This section focuses on understanding and analyzing security alerts within a Security Operations Center (SOC) workflow using Wazuh SIEM concepts. It covers alert classification, rule IDs, severity levels, timestamps, agent information, event descriptions, and investigation findings.

🛡️ The analysis emphasizes identifying suspicious activity, reviewing authentication and file-integrity events, assessing potential security impact, and documenting evidence-based observations. It also highlights the importance of validating alerts, distinguishing genuine threats from routine system activity, and following structured incident-response procedures.

📊 **Key Focus Areas:**
- Security alert triage and severity assessment
- Authentication and system-event analysis
- File Integrity Monitoring (FIM)
- Alert investigation and evidence documentation
- Incident response and security recommendations

🎯 **Objective:** Develop practical SOC investigation skills, improve security-event analysis, and maintain clear, structured documentation for cybersecurity assessment and continuous learning.
